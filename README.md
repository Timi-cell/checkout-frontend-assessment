# Crypto Checkout Frontend Quick Test

A simple crypto checkout interface built with Next.js, based on the provided Figma design.  
This project focuses on clean component structure, UI accuracy, responsiveness, and basic state handling.

---

## Setup Instructions

1. Clone the repository:


git clone <repository-url>


2. Navigate into the project directory:


cd crypto-checkout-frontend


3. Install dependencies:

npm install


4. Start the development server:

npm run dev


5. Open the application in your browser:

http://localhost:3000

---

## Tech Stack

* Next.js
* React JS
* TypeScript
* Tailwind CSS

---

## Assumptions & Trade-offs

* No backend integration was implemented; mock data was used as allowed in the assessment instructions.
* Only two screens from the provided Figma design were implemented, as required.
* Focus was placed on UI accuracy, responsiveness, and maintainable component structure over complex business logic.
* Validation and interactions were kept minimal to avoid overengineering.
* Standard icon libraries were used where appropriate for simplicity and consistency.
